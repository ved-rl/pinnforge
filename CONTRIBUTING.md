# Contributing to PINNForge

Thanks for wanting to help! Here's how:

## Reporting Bugs

Open an issue with:
- What you did
- What you expected
- What actually happened
- Your Python/PyTorch version

## Submitting Changes

1. Fork the repo
2. Create a branch (`git checkout -b feature/my-feature`)
3. Make your changes
4. Run tests (`pytest tests/`)
5. Commit and push
6. Open a Pull Request

## Code Style

We use Black for formatting. Run `black src/ tests/` before committing.
